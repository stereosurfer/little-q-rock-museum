# 設計筆記

## Stitch 輸出怎麼被使用

本機資料夾裡的 `stitch_import/` 是從 Stitch 匯出的參考資料，包含首頁、社群、商品/購物車、礦石詳細頁的設計稿與 HTML。這個資料夾只作為本機參考，不放進 GitHub repo。

目前網站沒有直接整包套用 Stitch 的程式碼，原因是 Stitch 匯出的 HTML 依賴 Tailwind CDN、Google Fonts 和外部圖片網址。現在採用的方式是：

- 保留原本可直接用 GitHub Pages 上線的純靜態結構。
- 吸收 `Mineral Discovery System` 的柔和自然觀察筆記風格。
- 新增「本月標本深入觀察」區塊，對應 Stitch 的礦石詳細頁概念。
- 保留已經可運作的購物車、留言牆與測試結帳流程。

## 設計方向

網站目前定位為「親子自然觀察筆記」而不是高級商業藝廊。視覺上偏向：

- 柔和的自然色：鼠尾草綠、天空藍、暖沙色。
- 大量留白：讓每顆標本像被放進展櫃中。
- 清楚的資料卡：方便孩子逐步補資料。
- 低門檻互動：先讓收藏、筆記、留言、購物車流程都能被理解。

## 暫不採用的 Stitch 內容

- 外部圖片網址：未來應換成自己拍攝的標本照片。
- Tailwind CDN：目前保持無建置流程，方便 GitHub Pages 直接部署。
- Google Fonts：目前先使用系統字體，減少外部依賴。
- 完整多頁架構：等內容量增加後再拆出獨立頁面。
