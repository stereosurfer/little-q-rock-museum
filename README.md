# 小Q的礦石博物館

一個給小小礦石收藏者的線上博物館。這個專案從礦石收藏展櫃開始，慢慢練習自然觀察、網站經營、愛好者社群和簡單電商流程。

目前網站是純靜態版本，可以直接用瀏覽器打開，也適合部署到 GitHub Pages。

## 專案目標

- 幫礦石收藏建立清楚、有故事感的線上展櫃。
- 讓孩子練習整理標本資料、撰寫觀察筆記和分享收藏。
- 讓家長練習網站版本管理、部署、購物車和未來金流整合。
- 先用安全、簡單的靜態網站起步，再逐步加入後端、會員或真正社群功能。

## 目前功能

- 收藏展櫃：顯示礦石名稱、分類、地點、日期、硬度、顏色與故事。
- 分類篩選：依礦物家族快速篩選展品。
- 本月標本：用較完整的資料卡展示一顆重點礦石。
- 館長筆記：記錄採集、整理和觀察計畫。
- 留言牆：提供本機端的留言體驗，適合先練習社群互動流程。
- 小商店：包含商品卡、購物車、數量調整與測試結帳。

## 如何打開網站

直接用瀏覽器開啟：

```text
index.html
```

或在專案資料夾中啟動任何靜態網站伺服器，再瀏覽首頁。

## 如何更新內容

主要資料集中在 `app.js`：

- `specimens`：新增或修改礦石展品。
- `products`：新增或修改商店品項。
- `timelineItems`：更新館長筆記的時間線。
- `starterMessages`：設定留言牆初始留言。

每一顆礦石建議至少記錄：

- 名稱
- 分類
- 來源或收藏位置
- 採集或入手日期
- 硬度
- 顏色
- 一段孩子自己寫的觀察故事

## 上線方式

這個版本最適合先部署到 GitHub Pages：

1. 將 repo 設為 public，或使用支援 private repo 的部署方案。
2. 在 GitHub repo 的 Pages 設定中選擇 `main` 分支。
3. 選擇根目錄作為發布來源。
4. 等待 GitHub Pages 產生公開網址。

也可以部署到 Netlify 或 Vercel。若未來加入真正訂單、金流、會員或公開留言資料，建議再加入後端服務。

## 專案路線圖

- 新增每顆礦石的獨立詳細頁。
- 改用真實礦石照片，並補上圖片授權或來源紀錄。
- 將留言牆改成真正的雲端資料。
- 增加管理後台，讓家人不用改程式也能新增標本。
- 串接金流測試環境，建立正式購物流程。
- 加上自訂網域和基本網站分析。
